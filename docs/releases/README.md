# Registros de versiones

Aquí se conservan los documentos `RELEASE_*` y las notas localizadas históricas.
Cada archivo mantiene su fecha y evidencia: una nota antigua que diga
«pendiente» describe ese momento, no necesariamente el estado actual.

La candidata y versión publicada actuales se describen en
[Estado del proyecto](../PROJECT_STATUS.md). Los manifiestos canónicos de
publicación permanecen en [release-manifests](../../release-manifests).
El [Changelog](../CHANGELOG.md) conserva el resumen público.

Estos documentos no sustituyen a la [arquitectura vigente](../ARCHITECTURE.md)
ni autorizan una publicación.
